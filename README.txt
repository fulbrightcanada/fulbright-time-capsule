FULBRIGHT AT 80 — TIME CAPSULE WEBSITE

GitHub Pages-ready static website.
1. Extract this ZIP.
2. Upload the CONTENTS of this folder to the root of your GitHub repository (not the enclosing folder).
3. Commit changes. GitHub Pages will publish the update automatically.

Files: index.html, styles.css, app.js, capsule-data.js, assets/
The site uses only the Fulbright 80th anniversary seal for branding.
Privacy: contact emails and administrative entry PDFs are not published. Malaika Serrano is featured first.
Large video files are not included to keep the site manageable for GitHub Pages; the original uploads remain in your source archive.
Flickr photos are remotely hosted by Flickr and link to Fulbright Canada's official album. If a Flickr image URL changes, update window.FULBRIGHT_FLICKR in capsule-data.js.
Historical timeline: https://www.fulbright.ca/timeline
Contribution form: https://www.cognitoforms.com/FulbrightCanada1/Fulbright80TimeCapsule
